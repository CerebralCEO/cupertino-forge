# Screen patterns

Each recipe lists the structure Claude must build. Adapt content, keep structure.

## Settings (iOS)

Large title "Settings", search at bottom or below title, insetGrouped list. First section: account row (60 avatar, name title3 emphasized, subtitle). Then sections of Settings style rows (29 squircle colored icons, body label, trailing value label-2 and chevron). Toggles trailing. Footers explain consequences. No save button: changes apply immediately.

## Settings (macOS)

Separate window, toolbar panes or sidebar, grouped forms (label leading, control trailing), Reset or Restore Defaults bordered button bottom of a pane only when needed.

## Onboarding (iOS)

1 to 3 screens max. Centered layout: hero glyph or illustration (up to 120), title1 emphasized, body label-2 (max 3 lines), feature list of 3 rows (accent glyph 28 leading, headline title, subheadline label-2 description), primary large filled button pinned to the bottom ("Continue"), secondary plain button below ("Not Now"). Permissions are asked in context, not during onboarding.

## Sign in

Large title "Sign In" or app name, insetGrouped fields (email, password with SecureField), primary filled large button, "Sign in with Apple" style button only when using that provider (follow provider brand rules), plain "Forgot Password?" link. Autofill content types set. Errors inline under the field.

## List to detail

List (plain or grouped) with chevron rows pushes a detail screen: large title off on detail (inline title), header (media or title2 emphasized and subheadline metadata), then grouped sections of info rows, actions in the navigation bar or bottom toolbar. iPad and Mac: split view with the list in the leading column and the detail on the right.

## Compose / create

Sheet at large detent: Cancel (leading plain), title, Add or Send (trailing tinted glass circle with arrow.up or checkmark). Content fields directly on bg without borders. Dismiss with unsaved changes asks via confirmation dialog.

## Search

Search field at the bottom (iPhone) or top (iPad, Mac). Before typing: recent searches list and suggestions. While typing: results grouped by type with section headers, matched text emphasized. No results: empty state "No Results for "query"" with suggestion.

## Dashboard / summary (Health, Fitness style)

Large title with date subtitle. Grid or list of summary cards (bg-2, radius 22, 16 padding): small header row (caption1 emphasized in the card's semantic color with glyph, trailing timestamp caption1 label-2), big value (title1 emphasized tabular) with unit (subheadline label-2), small chart. Tap pushes detail. No gauges with gradients, no neon.

## Profile / account

Header: avatar 80 circle centered, name title2 emphasized, subtitle subheadline label-2, then insetGrouped sections. Edit button top trailing.

## Paywall / purchase

Glass close circle top trailing, hero, title1 emphasized, 3 feature rows, plan selector as list rows with radio style checkmarks (or two cards side by side with accent 2 outline on selected), price in title3 emphasized with period footnote label-2, large filled button "Continue" or "Subscribe", footnote with terms and restore purchases plain button. Honest, calm, no fake countdowns.

## Media player

Full bleed artwork (squircle 12 inside padding when not playing full screen), title title3 emphasized, artist subheadline label-2, scrubber (slider with elapsed and remaining caption2 tabular), transport buttons (play 44 to 60 glyph without background, or clear glass circles over artwork), glass bottom controls.

## Chat

Plain list of bubbles: outgoing accent bubble with white body text, incoming fill-3 (light gray5) bubble with label text, radius 18 with tail optional, 2 gap within a group, 8 between groups, timestamps centered caption2 label-2. Composer: glass capsule at the bottom with plus circle leading and arrow.up.circle.fill accent trailing send.

## Desktop app shell (macOS)

Window with unified toolbar, sidebar (sections and rows), content (list or grid), optional inspector, all actions mirrored in the menu bar with shortcuts, Cmd+K command palette only if the app is a power tool (glass panel centered 600 wide, search field capsule, results list with shortcut hints).
