TITLE: scrollEdgeEffectStyle(_:for:)
URL: https://developer.apple.com/documentation/swiftui/view/scrolledgeeffectstyle(_:for:)

ABSTRACT: Configures the scroll edge effect style for scroll views within this hierarchy.
DECL: nonisolated func scrollEdgeEffectStyle(_ style: ScrollEdgeEffectStyle?, for edges: Edge.Set) -> some View


## Discussion
By default, a scroll view renders an automatic edge effect. Use this modifier to change the scroll edge effect style.
```swift
ScrollView {
    LazyVStack {
        ForEach(data) { item in
            RowView(item)
        }
    }
}
.scrollEdgeEffectStyle(.hard, for: .all)
```
